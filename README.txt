SIMPLE INVOICE — WINDOWS DOWNLOAD

QUICK START
1. Extract this ZIP file to a folder.
2. Double-click Simple_Invoice_App.html.
3. If asked, open with Microsoft Edge or Google Chrome.

FEATURES
- Create invoices with your business and customer details.
- Add/remove product or service lines, quantities and rates.
- Calculate subtotal, discount, tax and total.
- Print invoices or choose “Save as PDF” in the print dialog.
- Download an invoice as an HTML file.
- Save invoice records in the current browser on this PC.
- Download/import JSON backups to preserve or move invoices.

IMPORTANT
This is a local browser app, not a standalone EXE installer. Saved invoices use browser storage on this Windows profile. Download backups regularly. Clearing browser site data may remove locally saved records.
